# ghidorah

ghidorah は、Windows と Linux で独自の protocol による UDP の音声の送受信を C++ と Python から使う tool です。

[GitHub Release](https://github.com/sync-dev-org/ghidorah/releases) から wheel を取得し、`WHEEL_FILE` をその path に置き換えて `python -m pip install WHEEL_FILE` で install できます。
